# Render Deployment

## Render settings

Use these settings if creating the service manually in the Render Dashboard:

- Runtime: Python
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 120`
- Health Check Path: `/healthz`

The included `render.yaml` uses the same settings for Blueprint deployment.

## Required environment variables

Set these in Render before deploying:

- `FLASK_ENV=production`
- `FLASK_DEBUG=0`
- `FLASK_SECRET`: generated by Render or a long random value
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD` or `ADMIN_PASSWORD_HASH`
- `MYSQL_HOST`
- `MYSQL_PORT=3306`
- `MYSQL_DATABASE`
- `MYSQL_USER`
- `MYSQL_PASSWORD`
- `MYSQL_CONNECT_TIMEOUT=10`
- `GROQ_API_KEY`
- `GROQ_MODEL=llama-3.1-8b-instant`

Render does not provide managed MySQL. Use an external MySQL provider and enter its connection values above.

## Deploy with Blueprint

1. Commit and push this project to GitHub, GitLab, or Bitbucket.
2. In Render, create a new Blueprint from the pushed repository.
3. Fill all `sync: false` environment variables.
4. Apply the Blueprint.

## Deploy manually

1. Create a new Render Web Service from the pushed repository.
2. Use the build and start commands above.
3. Add the required environment variables.
4. Deploy.
